# CodeAlpha_simple-E-commerce-Store
Simple &amp; Direct: A basic e-commerce store application built with [Insert Technology, e.g., HTML/CSS/JavaScript] featuring product browsing and cart functionality.  Feature-Focused: A clean and responsive e-commerce web store template. Includes product listings, a shopping cart, and a checkout interface.  
## Run it

1. Clone the repo and open a terminal in the project folder.
2. Install dependencies:
python -m pip install -r requirements.txt

3. Start the server:

python -m uvicorn main:app --reload

4. Open http://127.0.0.1:8000 in your browser.

**Requires Python 3.10–3.12.** If you're on a very new Python version (3.13+) and see a
`ModuleNotFoundError`, reinstall with:

python -m pip install --force-reinstall -r requirements.txt
